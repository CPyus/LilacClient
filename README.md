# Lilac Client 

Lilac Client is a community-driven Minecraft mod built around one idea: **the community decides what gets added.**

Feature suggestions come from social media, videos, and community discussions. The most popular ideas get picked up and developed into actual features.

Rather than following a fixed development roadmap, Lilac Client evolves alongside the people who use it.

## How It Works

1. Share feature ideas and suggestions through the community.
2. Let the community decide what they'd like to see.
3. Pick a winning suggestion.
4. Develop and release the feature.
5. Start again.

## Development

Lilac Client is currently in development.

More information about supported Minecraft versions, features, and installation will be added as the project takes shape.

## Community

Have an idea? Leave a comment on the latest Lilac Client video or join the community discussion.
